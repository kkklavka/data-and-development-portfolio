
# Data & Development Portfolio

Портфолио проектов в области анализа данных, автоматизации и разработки приложений.

## Projects

### Retail Shop Demo

Full-stack веб-приложение магазина с пользовательской и административной частями.

**Основные возможности:**

- регистрация и авторизация пользователей;
- каталог товаров и корзина;
- оформление и отслеживание заказов;
- административная панель;
- кассовый интерфейс;
- сканирование QR-кодов товаров;
- электронные чеки;
- бонусная программа;
- история заказов и чеков.

**Стек:**
React, Node.js, Express, PostgreSQL, Sequelize, Material UI, JWT, Socket.IO.
