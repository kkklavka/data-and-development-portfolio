# Data & Development Portfolio

Портфолио проектов в области анализа данных, автоматизации и разработки приложений.

## 01. Web Development

### Retail Shop Demo

Full-stack веб-приложение магазина с пользовательской и административной частями.

**Стек:** React, Node.js, Express, PostgreSQL, Sequelize, Material UI, JWT, Socket.IO.

**Реализовано:**

* регистрация и авторизация;
* каталог товаров и корзина;
* оформление и отслеживание заказов;
* административная панель;
* управление статусами заказов;
* кассовый интерфейс;
* QR-сканирование товаров;
* электронные чеки;
* бонусная программа.

[Открыть проект](./01-web-development/retail-shop-demo/)

## 02. Data Analysis

### Анализ загрузки касс и покупательского потока

Анализ транзакционных данных розничного магазина в Jupyter Notebook.

Проект включает исследование нагрузки касс, среднего размера корзины, пиковых часов продаж, необходимого количества кассиров и товарных паттернов.

**Инструменты:** Jupyter Notebook, pandas, NumPy, Matplotlib, Seaborn, SciPy.

**Методы:**

* очистка и подготовка данных;
* группировка и агрегация;
* анализ временных периодов;
* визуализация;
* сводные таблицы;
* χ²-тест;
* Cramér's V;
* корректировка множественных проверок Benjamini–Hochberg;
* формирование бизнес-выводов.

[Открыть проект](./02-data-analysis/01-cashier-load/)
