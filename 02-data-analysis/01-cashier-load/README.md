# Retail Data Analysis

Демонстрационный аналитический кейс по оценке загрузки касс и покупательского потока в розничном магазине.

Проект основан на реальной бизнес-задаче, но все данные в репозитории **синтетические**: названия касс, товаров, даты и транзакции не относятся к реальной компании.

## Основной формат

Анализ оформлен как последовательный **Jupyter Notebook** с кодом, таблицами, графиками и выводами. Notebook можно просматривать прямо на GitHub.

[Открыть notebook](notebooks/retail_analysis.ipynb)

## Задача

По транзакционным данным нужно определить:

- какие кассы получают наибольшую нагрузку;
- как отличается размер корзины между кассами;
- в какие дни недели и часы возникает пиковый поток;
- сколько кассиров требуется в разные временные интервалы;
- какие товары чаще встречаются в пиковые часы;
- есть ли статистически заметная связь между отдельными товарами и кассами.

## Что показано в notebook

- загрузка и валидация Excel-данных;
- очистка типов и пропусков;
- `groupby`, `pivot`, `crosstab`, категориальные признаки;
- агрегация товарных строк до уровня чека;
- анализ размера корзины и загрузки касс;
- анализ пиковых часов и дней недели;
- визуализация покупательского потока;
- сценарный расчёт требуемого количества кассиров;
- χ²-тест независимости и Cramér's V;
- коррекция множественных проверок Benjamini–Hochberg;
- формирование итогового Excel-отчёта.

## Инструменты

Jupyter Notebook, pandas, NumPy, SciPy, Matplotlib, openpyxl, Excel.

## Формат входных данных

| Поле | Описание |
|---|---|
| `receipt_id` | идентификатор чека |
| `datetime` | дата и время продажи |
| `cash_register` | касса |
| `product` | товар |
| `quantity` | количество единиц товара |

## Конфиденциальность

В репозитории нет исходных рабочих выгрузок. Используется только синтетический демонстрационный набор данных, сохраняющий структуру аналитической задачи без раскрытия информации реальной компании.
