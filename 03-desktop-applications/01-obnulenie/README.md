# Обнуление товаров — desktop-анализ запасов

Desktop-приложение на Python/Tkinter для обработки Excel-выгрузок 1С типа «Ведомость по товарам на складах». Проект рассчитывает темп продаж, запас в днях и рекомендуемый заказ, учитывая поставщика и график поставок.

## Что показывает проект

- обработку и преобразование Excel-файлов через `openpyxl`;
- парсинг нестандартных выгрузок 1С и восстановление проблемных `.xlsx`;
- бизнес-логику управления запасами и пополнением;
- сопоставление товара с основным поставщиком;
- расчёт горизонта заказа по графику поставок;
- GUI на `Tkinter` с обработкой файлов в отдельном потоке;
- сборку Windows `.exe` через `PyInstaller`;
- автоматические тесты ключевой расчётной логики.

## Расчёты

Для каждого товара приложение добавляет три показателя:

- **Темп продаж** = расход / количество календарных дней периода;
- **Запас в днях** = конечный остаток / темп продаж;
- **Рекомендуемый заказ** = `max(0, темп продаж × дни до следующего завоза − конечный остаток)` с округлением вверх до целой единицы.

Период считается **включительно**: например, `01.07.2026–07.07.2026` — 7 календарных дней.

Если для товара найден основной поставщик и его график, горизонт заказа определяется по самому длинному интервалу между поставками. При необходимости к нему добавляется страховой запас. Если связка не найдена, используется резервное число дней из интерфейса.

## Дополнительная обработка

Приложение:

- подсвечивает нулевой конечный остаток;
- подсвечивает запас менее 7 дней;
- сортирует позиции по запасу в днях;
- добавляет автофильтр и фиксирует шапку;
- добавляет комментарий к рекомендуемому заказу с причиной решения;
- умеет обрабатывать несколько Excel-файлов за один запуск;
- не блокирует GUI во время расчёта;
- пытается исправить некоторые некорректные `.xlsx` из 1С и, на Windows, может использовать установленный Excel как резервный способ пересохранения.

## Структура

```text
.
├── programma_obnulenie_app.py   # приложение и расчётная логика
├── supplier_map.xlsx            # обезличенный демонстрационный справочник
├── delivery_schedule.xlsx       # обезличенный демонстрационный график
├── examples/
│   └── demo_1c_report.xlsx      # тестовая выгрузка в формате, похожем на 1С
├── tests/
│   └── test_core.py             # тесты расчётов
├── RUN_APP.bat                  # запуск в Windows
├── INSTALL_LIBRARIES.bat        # установка runtime-зависимостей
├── BUILD_EXE.bat                # сборка EXE
├── Obnulenie.spec               # конфигурация PyInstaller
├── requirements.txt
└── requirements-dev.txt
```

## Запуск

### Windows — простой вариант

1. Установить Python 3.11+.
2. Запустить `INSTALL_LIBRARIES.bat`.
3. Запустить `RUN_APP.bat`.
4. Выбрать один или несколько `.xlsx`-отчётов.
5. Выбрать папку для готовых файлов.
6. Нажать **«Сформировать готовые файлы»**.

Для быстрой проверки можно выбрать `examples/demo_1c_report.xlsx`.

### Через терминал

```bash
python -m pip install -r requirements.txt
python programma_obnulenie_app.py
```

## Тесты

```bash
python -m pip install -r requirements-dev.txt
pytest -q
```

## Сборка EXE

```text
BUILD_EXE.bat
```

Готовый файл создаётся в `dist/Obnulenie.exe`.

## Формат справочников

`supplier_map.xlsx` должен содержать колонки:

- `Номенклатура`
- `Основной поставщик`

`delivery_schedule.xlsx` должен содержать колонки:

- `День поставки`
- `Поставщик`
